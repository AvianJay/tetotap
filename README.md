# tetotap
重音テト（Kasane Teto）版的 Mikutap，基于 [HFIProgramming/mikutap](https://github.com/HFIProgramming/mikutap)（https://aidn.jp/mikutap 的独立移植版）修改  

# 致所有自行编辑修改的人

请在任何时候**不要移除原作者信息**。你可以添加你自己名字上去，但是保留原作者信息是最基本的尊重。

如果你用于了推广、广告等用途，请参见下方许可证要求联系原作者，谢谢。

# Tetotap 修改说明  
- 32 段人声全部换成重音テト演唱（官方 UTAU 单独音音源），音高、节奏、长度与音量都对齐原版
- 背景音乐保持原版
- 配色改为重音テト的红色系（主色取自官网的 #D5214B）
- 标题、图标与“关于”页面改为 Tetotap / 重音テト

# 为什么要做这个  
因为很有趣，觉得应该分享给大家，降低国内用户访问的成本  
Related: https://www.v2ex.com/t/403054#reply0
